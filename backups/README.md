# โฟลเดอร์สำรองข้อมูล

ที่วางไฟล์สำรอง `.json` ที่ส่งออกจากหน้าจอ **การจัดการระบบ → สำรองข้อมูล**

## วิธีใช้

1. เปิดหน้า **การจัดการระบบ → สำรองข้อมูล**
2. กด **เลือกโฟลเดอร์ปลายทาง** แล้วชี้มาที่โฟลเดอร์นี้ (หรือโฟลเดอร์ `UltraERP-Backup`
   ที่สร้างไว้เองในเครื่อง เช่นที่ Documents)
3. กด **สำรองข้อมูลเดี๋ยวนี้** ไฟล์จะถูกเขียนลงโฟลเดอร์ที่เลือกทันที

เบราว์เซอร์ที่ไม่รองรับการเลือกโฟลเดอร์ (Safari, Firefox) ยังสำรองได้ตามปกติ
แค่ไฟล์จะไปอยู่ที่โฟลเดอร์ดาวน์โหลดแล้วค่อยย้ายมาเอง

## ไฟล์สำรองมีอะไรบ้าง

ทุกตารางในระบบ — คลัง ช่องเก็บ สินค้า การจัดวาง รายการเคลื่อนไหว บิล POS
ลูกค้า เจ้าหนี้ ใบขาย ใบซื้อ ใบส่งคืน กลุ่มเอกสาร ข้อมูลกิจการ และสิทธิการใช้งาน

ไฟล์เดียวกู้กลับมาได้ครบทั้งระบบ

## ทำไมไฟล์ .json ในโฟลเดอร์นี้ไม่ถูกเก็บขึ้น git

เป็นข้อมูลจริงของแต่ละที่ ไม่ใช่โค้ด — มีทั้งชื่อลูกค้า ที่อยู่ และยอดขาย
ไม่ควรอยู่ในที่เก็บโค้ดที่คนอื่นเข้าถึงได้ `.gitignore` จึงกันไว้ให้แล้ว
