# Overview
จัดทำโปรแกรมควบคุมสินค้าคงคลัง
โทนสีเขียวของการยางแห่งประเทศไทย
มีหน้าจอ รับสินค้า เบิกสินค้า โอนสินค้า การปรับปรุงสินค้า

มีหน้าจอกำหนดรายละเอียดสินค้า ใส่รูป ใส่บาร์โค๊ดได้
มีหน้าจอแสดงสินค้าที่อยู่ในแต่ละจังหวัด อ้างอิงแผนที่จาก google map
มีการพิมพ์รายงานการตรวจนับสินค้า
มีกราฟสรุปปริมาณขึ้นลงคงเหลือ

 # Deployment
- ใช้ Vercel + NextJS
- ไม่ต้องติดตั้งอะไรทั้งสิ้น (ในเครื่องผู้ใช้)

  วิธีที่ทำ: Vercel จะรัน `npm install` และ `next build` ให้เองบนคลาวด์
  ผู้ใช้ไม่ต้องติดตั้ง Node.js หรือ npm ในเครื่องเลย แค่ push โค้ดหรือลากโฟลเดอร์ขึ้น Vercel
  (ถ้าอยากรันในเครื่องเองภายหลัง ค่อยใช้ `npm install` แล้ว `npm run dev`)


# Stack ที่ใช้
- Next.js 15 (App Router)
- React 19
- JavaScript ล้วน (ไม่ใช้ TypeScript) เพื่อลดขั้นตอน
- CSS ธรรมดาไฟล์เดียว (app/globals.css) ไม่ใช้ Tailwind / CSS-in-JS
- ไม่มี dependency อื่นเลยนอกจาก next / react / react-dom
  * ไอคอนทั้งหมด = inline SVG เขียนเอง
  * บาร์โค๊ด = Code 128-B encoder เขียนเอง (lib/barcode.js)
  * กราฟ = inline SVG เขียนเอง (components/Charts.js) ไม่ใช้ Chart.js
  * แผนที่ = Google Maps Embed ผ่าน iframe (ไม่ต้องใช้ API key)
- เก็บข้อมูลด้วย localStorage ตามข้อกำหนด "ไม่ต้องใช้ Database"

# วิธี Deploy ขึ้น Vercel
วิธีที่ 1 — ผ่าน Git (แนะนำ):
  1. push โฟลเดอร์นี้ขึ้น GitHub
  2. เข้า https://vercel.com/new แล้ว Import repository
  3. Vercel ตรวจเจอ Next.js เอง — ไม่ต้องตั้งค่าอะไรเพิ่ม กด Deploy
  4. Vercel รัน npm install + next build ให้บนคลาวด์

วิธีที่ 2 — ลากวาง:
  1. เข้า https://vercel.com/new
  2. ลากโฟลเดอร์ Web-Workshop3 ทั้งโฟลเดอร์ไปวาง (อย่ารวม node_modules)
  3. กด Deploy

ไม่ต้องมี vercel.json — Vercel ตรวจจับ Next.js จาก package.json ได้เอง

# ข้อมูลตัวอย่างที่สร้างให้ (แก้ไข/ลบได้ทั้งหมด)
- สินค้า 12 รายการ: น้ำยางข้น 60%, RSS3, STR 20, ยางเครพ, ถุงมือยาง, หมอนยางพารา,
  แผ่นยางปูพื้น, กรดฟอร์มิก, ปุ๋ย 20-8-20, ถ้วยรองน้ำยาง, มีดกรีดยาง, ถังเก็บน้ำยาง
- คลัง 10 แห่ง 10 จังหวัด: กรุงเทพฯ, สุราษฎร์ธานี, สงขลา, นครศรีธรรมราช, ตรัง,
  ยะลา, ระยอง, บึงกาฬ, อุบลราชธานี, เชียงราย (มีพิกัด lat/lng สำหรับ Google Map)
- รายการเคลื่อนไหว 431 รายการ ย้อนหลัง 8 เดือน (ใช้ตัวสุ่มแบบ seed คงที่
  ข้อมูลจึงเหมือนกันทุกครั้งที่รีเซ็ต)
- ปุ่ม "ข้อมูล" มุมขวาบน = ส่งออก/นำเข้าไฟล์สำรอง และล้างข้อมูลสร้างใหม่


# ผลการทดสอบ (2026-08-27)

ก. ตรวจโครงสร้างโค้ด 30 ไฟล์ — ผ่านทั้งหมด
   - import ทุกเส้นทางมีไฟล์จริง และชื่อ named import มี export จริง
   - วงเล็บ/ปีกกาสมดุลทุกไฟล์
   - ไฟล์ที่ใช้ React hook ประกาศ "use client" ครบ
   - ไม่มีการเรียก localStorage/window/document ที่ระดับ module (กัน SSR พัง)
   - แท็ก void ใน JSX ปิดตัวเองครบ

ข. ทดสอบตรรกะหลักด้วย Node 40 ข้อ — ผ่านทั้งหมด
   บาร์โค๊ด Code 128-B        ตาราง 107 รายการ, จำนวนแท่งตรงสเปก, กรองอักขระนอก ASCII
   ข้อมูลตั้งต้น              จำนวน/ความครบถ้วน/การอ้างอิง/การเรียงเวลา/สร้างซ้ำได้ผลเดิม
   การคำนวณยอด               stockMap 120 คู่, ผลรวมรายสินค้า = รายคลัง (186,457),
                              คำนวณด้วยมือตรงกับ stockMap
   ตรรกะการโอน                ต้นทางลด/ปลายทางเพิ่ม/คลังอื่นไม่กระทบ,
                              ยอดรวมทั้งองค์กรไม่เปลี่ยน
   เลขที่เอกสาร               รูปแบบครบ 4 ประเภท, เดินหน้าทีละ 1, ขึ้นเดือนใหม่รีเซ็ต, ไม่ซ้ำ
   การจัดรูปแบบ               คอมมา, ปี พ.ศ., uid ไม่ซ้ำ 500 ครั้ง, rng คงที่

ค. ยังไม่ได้รัน `next build` จริง
   เพราะต้อง `npm install` ก่อน ซึ่งขัดกับข้อกำหนด "ไม่ต้องติดตั้งอะไรทั้งสิ้น"
   Vercel จะ build ให้เองตอน deploy — ถ้าอยากตรวจก่อน ให้รัน:
       npm install
       npm run build


# ข้อจำกัดที่ควรทราบ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องที่ใช้งานเท่านั้น
  ไม่แชร์ข้ามเครื่อง/ข้ามผู้ใช้ และล้าง cache แล้วข้อมูลจะหาย
  (เป็นไปตามข้อกำหนด "ไม่ต้องใช้ Database")
  ควรใช้ปุ่ม "ข้อมูล" > ส่งออกไฟล์สำรอง เป็นระยะ
- รหัสผ่านเป็นแบบ Fixed อยู่ในโค้ดฝั่ง client ใช้สำหรับสาธิต/ใช้งานภายในเท่านั้น
  ใครเปิด DevTools ก็เห็นรหัสได้ ไม่เหมาะกับการเปิดสาธารณะที่มีข้อมูลจริง
- แผนที่ต้องเชื่อมต่ออินเทอร์เน็ต (Google Maps Embed) ส่วนอื่นทำงาน offline ได้
